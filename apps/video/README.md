# Video workspace

This package contains local Remotion compositions for TripleKeel.

Start Remotion Studio from the repository root:

```sh
pnpm video:studio
```

Render the starter composition to `apps/video/out/triplekeel-intro.mp4`:

```sh
pnpm video:render
```

Add new compositions in `src/` and register them in `src/Root.tsx`.
